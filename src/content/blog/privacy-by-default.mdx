Wraith brings privacy by default to payment experiences. Rather than asking developers to bolt on confidentiality after the fact, stealth addressing is part of the core send flow.

- **No shared addresses:** recipients publish a meta-address; real destinations stay hidden.
- **Same chains, new privacy:** EVM and Stellar work unchanged under the hood.
- **Built for apps:** the SDK returns a signed transaction you can broadcast like any other.

Privacy should be the default state of a payment, not a premium add-on.
