# Design Rationale

## Hero

Recommend the code-first refined direction.

- Keeps the page developer-oriented and consistent with the existing site tone.
- Preserves the current clean layout while adding a clear Stellar partnership signal.
- Supports a lightweight, composable hero that can be implemented without heavy animation.

## Chains

Recommend the Stellar-prominent chain grid.

- Highlights Stellar as a strategic partner while keeping the chain list simple.
- Uses visual weight and a small callout to reinforce the partnership without changing page structure.
- Provides a direct path to implementation and preserves the existing grid style.
